## Proyecto: SatellAgro
Todas las entregas de la materia giran alrededor de nuestro proyecto, **SatellAgro**: una señal satelital (Sentinel-2) que le indica al productor de vid de Mendoza **qué cuartel conviene ir a mirar** por posible estrés hídrico, con la fecha de la imagen y un nivel de confianza. El sistema recomienda; el productor decide.

| Módulo | Tema | Entrega |
|---|---|---|
| [Módulo 1](Modulo%201) | Toma de decisiones | Selección del enfoque tecnológico (Sentinel-2 vs. térmico vs. sensores) con matriz multicriterio |
| [Módulo 2](Modulo%202) | Redacción con IA | Plan del piloto SatellAgro 2026–27 |
| [Módulo 3](Modulo%203) | Taller de fotografía | Análisis pericial de una imagen satelital y de una falsa alarma |
| [Módulo 4](Modulo%204) | QGIS / SIG | Cuarteles, canales y bodegas de Agrelo + NDVI/NDMI, con dos mapas web interactivos |
| [Módulo 5](Modulo%205) | Dinámica de sistemas | Modelo Vensim de difusión por cauces de riego, validación y pruebas STEP |

La carpeta `_fuentes` contiene el código fuente (HTML) de los informes y el script que genera los PDF.
